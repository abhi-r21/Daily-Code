# 💻 Daily-Code

Welcome to **Daily-Code** — my journey of learning, practicing, and improving my programming skills one day at a time.

This repository contains my daily coding exercises, programming challenges, and practice problems as I build a strong foundation in software development. My goal is to improve my problem-solving skills, strengthen my understanding of programming concepts, and develop the consistency needed to become a better developer.

## 🎯 Goals

- Build a consistent daily coding habit.
- Strengthen programming fundamentals and logical thinking.
- Practice JavaScript, Python, and backend development concepts.
- Solve coding problems from beginner to advanced levels.
- Write clean, readable, and maintainable code.
- Track my learning progress through Git and GitHub.

## 🛠️ Languages & Technologies

### 1. JavaScript

Practicing JavaScript fundamentals, problem-solving, functions, arrays, objects, asynchronous programming, and modern ES6+ features.

**Documentation:** [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)

### 2. Python

Learning Python fundamentals, syntax, data structures, functions, loops, and problem-solving, with a focus on using Python for backend development and AI-related applications.

**Documentation:** [Official Python Tutorial](https://docs.python.org/3/tutorial/)

### 3. Backend Development

Practicing backend programming concepts, HTTP servers, request and response handling, REST APIs, and other essential server-side development fundamentals.

**Documentation:**
- [Node.js](https://nodejs.org/docs/latest/api/)
- [Express.js](https://expressjs.com/)
- [HTTP — MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/HTTP)

### 4. TypeScript

Exploring static typing, type annotations, interfaces, and other TypeScript features to write safer and more maintainable JavaScript applications.

**Documentation:** [Official TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
